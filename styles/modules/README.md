# Module styles

Module CSS is generated by each module controller and injected into a plugin-owned
`<style>` element only while the matching module and target are active. Each module
is responsible for its target detection, settings validation, selectors, observer,
live updates, and cleanup.

The current V1 module contracts live in `modules/kanban/`,
`modules/spaced-repetition/`, and `modules/bases/`. Do not add a module by
editing this note alone; register a complete module in `modules/index.js`.
