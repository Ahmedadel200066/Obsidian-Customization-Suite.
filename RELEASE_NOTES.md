# Customization Studio 1.3.0

## What's new

- A version-aware What's new dialog shows release highlights once after an update. Fresh installs stay quiet.
- Reopen the notes at any time with the **Show what's new** command or the button in Customization Studio settings.
- A centered Buy Me a Coffee button offers an optional way to support development. Its icon is bundled inline, with no remote image request.

## Fixes

- Ribbon settings now scroll even when an older installed stylesheet or a conflicting theme rule hides overflow.
- Runtime scroll sizing keeps the modal within the viewport and adapts to window and mobile viewport changes.

## Installation and update

Download **main.js**, **manifest.json**, and **styles.css** from this release and replace all three files in your vault's `.obsidian/plugins/customization-studio/` folder. Disable and re-enable Customization Studio afterward, or restart Obsidian.

Minimum supported Obsidian version: **1.9.0**. Existing profiles and appearance settings are preserved.
